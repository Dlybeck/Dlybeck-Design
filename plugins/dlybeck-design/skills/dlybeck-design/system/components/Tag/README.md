# Tag

Small pill labels for categories, counts and filters.

- `dly-tag` plain; `dly-tag--on` for the selected or highlighted one (uses `hi`, one per group); `dly-tag--blue` for informational counts.
- Use a `<button class="dly-tag">` with `aria-pressed` when it toggles a filter.
- Status: a `dly-dot` in `ok`, `warn` or `bad` plus a word. Never color alone.
