# Deck

A stack of cards you deal through one at a time. Fling the top card off and it tucks underneath; a short drag eases back into place.

- Markup: `.dly-deck` (sized) containing `.dly-deck-card` papers. Call `Dly.Deck(box)`.
- Always pair it with a visible "Next" button: the fling and the two-finger swipe are bonuses, not the only way in. The top card nudges sideways on hover as its handle.
- Use for galleries, onboarding steps, flashcards, or sections shown as a hand of cards.
