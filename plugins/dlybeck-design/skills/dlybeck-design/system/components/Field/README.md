# Field

Text inputs with a label above, a `line-control` border, and a highlighter focus glow so the field you're in is obvious.

- Always a visible `<label>` tied by `for`/`id`. No placeholder-only fields.
- Helper text (`dly-help`) under the input in `ink-2`; errors (`dly-error`) in `bad`, saying what went wrong and how to fix it.
- Focus: `action` border plus a 4px `hi` glow.
