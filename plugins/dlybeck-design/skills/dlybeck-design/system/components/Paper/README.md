# Paper

A sheet of paper: the basic physical object. Nearly square corners, ink edge, paper color that stays the same in both themes.

- Colors: `dly-paper--lemon`, `--pink`, `--tangerine`, `--mint`, `--sky`, or the default off-white note. Color-code by branch or category; five at most per screen.
- Content: a mono label (`dly-paper-k`), a title (`dly-paper-h`), optional text (`dly-paper-s`). Text is always `ink-fixed`.
- Make it an `<a>` or `<button>` when it opens something; it lifts on hover.
- Hang it with Pinned, stack it with Deck, or tuck it with PullTab.
