# HoldButton

Press and hold to confirm. The button sinks into its shadow as you hold, filling with mint; let go early and it eases back up; finish and it says it's done.

- Use it instead of an "Are you sure?" dialog for actions people would hate to trigger by accident: sending, deleting, publishing, resetting.
- Not for ordinary actions. Holding adds a step, so it has to earn it.
- Label with a verb plus "hold": "Hold to send", "Hold to delete". Put the label in a `<span>`. Works with Space or Enter held down.
