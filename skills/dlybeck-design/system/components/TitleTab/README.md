# TitleTab

The brand hangs from the top edge like a folder tab. It is the Home link, it never scrolls with the content, and it leaves the corners free for one action each.

- One per page, at the top-left or top-center. Text is the person's or product's name in `on-brand` at 18px+ bold.
- Optionally carries the personal mark (28–40px) before the name.
- Keep `top: env(safe-area-inset-top)` when fixed.
